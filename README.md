# 空靈鼓跟敲助手

給空靈鼓初學者的跟敲練習程式。載入樂曲後按播放，鼓上要敲的音舌會亮起顏色，跟住敲就可以學識一首歌。

整個程式是一個 `index.html` 檔，不用安裝，用瀏覽器打開即可（電腦、平板、手機都可以）。

## 功能

- **兩款鼓**：D 調 11 音、D 調 15 音。
- **三種練習模式**：
  - 示範：播放鼓聲，同時亮起要敲的音舌。
  - 跟敲：只亮燈，不出鼓聲，自己跟住敲。
  - 等待：敲中亮起的音舌才會去下一個音，並記錄錯了幾次。
- **簡譜**：正式簡譜寫法，有減時線、增時線、附點、高低八度點、小節號和每拍拍數，播放時跟住移動；撳任何一個音可以跳去該位置。
- **拍子機式速度控制**：BPM 30–240、TAP 測速、2/4・3/4・4/4・6/8、預備拍、循環小節、漸進加速。
- **提示顏色**：單色、按音階（彩虹、鮮明、貼紙色、柔和、自訂）、左右手。
- **鼓面外觀**：24 款推薦款式（素雅、曼陀羅與幾何、東方、民族風、自然）；20 種固定鼓身顏色（包括陽極氧化漸變色）同 21 種花紋自由配搭。
- **背景顏色**：10 款深淺背景，亦可自訂。
- **音色**：5 種內置音色，預設為仿魯儒風格的「鈦金鋼」（膠槌／手指兩款），另有碳鋼、手碟、水晶鐘；可調殘響、空間大小、共鳴泛音、A=440／432 調音。
- **鼓聲八度**：11 音、15 音鼓各自可選低八度／標準／高八度（11 音鼓預設高八度，配合細尺寸鼓）。
- **真鼓聽音**：開咪後用真鼓敲，等待模式敲啱自動前進，跟敲模式自動計分（需要 HTTPS 網頁版及允許咪高峰；Claude 預覽版不支援）。
- **聽音認舌遊戲**：程式播音、學生搵返係邊個音舌，三個難度，記錄最佳成績。
- **練習紀錄**：每首歌最佳準確度同星星（★）、今日／近 7 日練習分鐘、連續練習日數，只儲存喺使用者裝置。
- **全螢幕**：上堂投影用。
- **真實錄音**：上載自己鼓的錄音，程式會自動分段、認出音高，再調準到鼓上每個音舌。
- **匯入樂曲**：MIDI 檔（自動揀旋律音軌及移調）或簡譜文字。

## 簡譜文字格式

```
TITLE=小星星
BPM=90
TIME=4/4
1 1 5 5 | 6 6 5 - | 4 4 3 3 | 2 2 1 - |
```

`1`–`7` 音　`0` 休止　`5,` 低八度　`1'` 高八度　`-` 延長一拍　`3/` 半拍　`3//` 四分一拍　`3.` 附點　`|` 小節線　`[1 3]` 同時敲

## 錄製真實音源

1. 用手機在安靜的地方錄音。
2. 由低至高逐個音舌敲一下，每個音之間停兩秒；一個檔錄晒全部音舌也可以。
3. 在「音色」面板上載錄音，程式會自動處理並轉用「真實錄音」音色。

未有錄音的話，Freesound 上有 hollandm 錄製的 11 音空靈鼓錄音（CC0）：<https://freesound.org/people/hollandm/packs/38732/>

## 修改程式

原始碼喺 `src/`，改完執行 `./build.sh` 會重新產生 `index.html`。

## 備註

- 設定、自訂樂曲和錄音只會儲存在使用者自己的瀏覽器內。
- 內置音色是即時合成的，不包含任何錄音檔。
